# Sleep and Awake Classification 😴👀

## 📌 Overview

This project uses **Deep Learning, YOLO, and Computer Vision** to classify images into two categories: **Sleep** and **Awake**. It includes an interactive Streamlit web application where users can upload an image and view the predicted class and confidence score.

## ✨ Features

- Sleep and awake image classification
- YOLO-based Deep Learning model
- Image upload through Streamlit
- Predicted class and confidence score
- Interactive web interface using `app.py`
- Image processing using OpenCV

## 🛠️ Technologies Used

- Python
- YOLO
- Ultralytics
- OpenCV
- Streamlit
- Deep Learning
- Computer Vision
